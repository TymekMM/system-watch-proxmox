# Contributing

Open an issue describing the proposed change before a large refactor. Keep installation supervised and simple. Add focused tests for meaningful behavior changes. Use one class per file for new types and retain namespaces/JSON contracts.

Run `bash build/test.sh` on Linux with .NET 10 and Node.js. Recipe contributions must include exact original/candidate hashes, reviewed scoped anchors, and results from a disposable matching Proxmox build. Never submit full private snapshots, host credentials, serial numbers, or proprietary utilities.

Contributions are under the GNU AGPL v3 license already used by this repository. Preserve third-party notices and identify copied material and its origin.
